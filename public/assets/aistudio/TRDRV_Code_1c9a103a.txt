3. HOW EVERY EXISTING ENGINE & TRADING TOOL WORKS INTERNALLY
====================================================================
1. Dual-Gateway Deriv Connection & Execution Architecture (`account-data.ts`, `deriv-client.ts`, `trade-execution.ts`, `websocket.ts`):
   - **WebSocket Cluster Race**: `DerivWebSocket` races official endpoints (`wss://red.derivws.com/websockets/v3`, `wss://ws.derivws.com/websockets/v3`, `wss://green.derivws.com/websockets/v3`, `wss://blue.derivws.com/websockets/v3`, `wss://ws.binaryws.com/websockets/v3`) using `Promise.any`, remembers `lastWorkingEndpoint`, maintains 30s keepalive pings, and auto-reconnects with exponential backoff.
   - **OAuth2 PKCE + Replay Guard**: Generates 32-byte `codeVerifier` + `S256` `codeChallenge`, AES-256-GCM encrypts `{ codeVerifier, redirectUri }` into JWT `state` with a one-time `jti` (stored in replay-guard map for 20 mins), exchanges authorization `code` at `POST https://auth.deriv.com/oauth2/token`, fetches accounts via `GET https://api.derivws.com/trading/v1/options/accounts` and nickname via `GET https://api.derivws.com/account/v1/nickname`. Supports both new `ory_at_...` OAuth2 tokens and legacy `?acct1=...&token1=...` callbacks.
   - **AES-256-GCM Token Vault**: Every user Deriv token is encrypted with AES-256-GCM (`encrypted_token`, `token_iv`, `token_auth_tag`) in `account_authorizations` and decrypted strictly server-side right before trade/sync calls.
   - **OTP Gateway vs Classic WebSocket Trade Execution**:
     * For `ory_at_...` OAuth2 tokens or PATs: calls `POST https://api.derivws.com/trading/v1/options/accounts/:id/otp` to obtain a one-time WebSocket URL (`OtpDerivClient`), using `underlying_symbol` field.
     * For classic tokens: authorizes on `DerivWebSocket` (`{ authorize: token }`) using `symbol` field, falling back to PAT OTP if rejected.
     * For Multiplier orders (`MULTUP` / `MULTDOWN`): queries `contracts_for` to validate `multiplier_range` (auto-snapping to accepted multipliers like 100/50/160 or parsing error messages for accepted values), converts price/USD/pips/% SL & TP into `limit_order: { take_profit, stop_loss }` USD values (enforcing SL < stake and >= 0.50 USD), sends `proposal` -> `buy`, updates `connected_accounts.last_known_balance`, broadcasts WebSocket `account_updated`, and inserts into `virtual_orders`. Automatically falls back to `CALL`/`PUT` (5 ticks) if multipliers are unsupported on the selected symbol.

2. MT5 TradingView Terminal (`MT5TradingView.tsx`, `OrderTicket.tsx`, `MarketWatchPanel.tsx`, `IndicatorsPanel.tsx`, `DrawingToolbar.tsx`, `TimeframesBar.tsx`):
   - **Chart Engine**: Built with `lightweight-charts` (`CandlestickSeries` + `LineSeries`), supporting all Deriv timeframes (`1t` / `1m` / `2m` / `3m` / `5m` / `10m` / `15m` / `30m` / `1h` / `2h` / `4h` / `8h` / `1d`), client-side overlays (**SMA 20**, **EMA 50**, **Bollinger Bands**), interactive **Drawing Toolbar** (Crosshair, Horizontal Price Line click-to-place, Undo, Redo, Show/Hide Drawings, Clear All), and live price lines (`Entry`, `TP`, `SL`) drawn directly on the chart.
   - **MarketWatchPanel**: Displays all 70+ Deriv symbols with category tabs (`All`, `Synthetic`, `Forex`, `Crypto`, `Metals/Cmd`, `Indices`), search bar, `★` watchlist filter synced to PostgreSQL `watchlists`, and live `Bid | Ask` columns. Resilient 3-tier loading: DB `market_instruments` -> Deriv `active_symbols` (4.5s timeout, no deprecated `product_type`) -> curated 70+ official Deriv symbols catalog fallback.
   - **OrderTicket (Lots + 4-Mode USD SL/TP + Bulk Open/Close)**:
     * **Volume, Lots**: `0.01` to `100.00` lots (`0.01` step <1.0, `0.10` step >=1.0), quick presets (`0.01`, `0.05`, `0.10`, `0.50`, `1.00`), synced 1:100 with USD Margin/Stake (`1.00 lot = $100`), plus leverage multipliers (`x50`, `x100`, `x200`, `x400`).
     * **Modes**: `MT5 Market`, `Over/Under` (digit barrier 0–9, tick duration 1–10), `Rise/Fall`.
     * **Bulk Order Count**: Dropdown (`1`, `2`, `3`, `5`, `10` positions at once, up to 25 via API).
     * **Stop Loss & Take Profit**: Toggleable switches with 4-unit selector (`Price`, `USD`, `Loss/Profit in %`, `Pips`) **defaulting to USD currency amount**, live auto-conversion when switching units, max-loss validation against stake, and Risk:Reward presets (`1:1`, `1:1.5`, `1:2`).
   - **Bottom MT5 Terminal Dock**: Shows live `Balance`, `Equity`, `Margin`, `Free Margin`, `Floating P/L`, tabs for `Open Positions`, `History`, and `Exposure Summary`, plus 7 Bulk Close buttons (`Close All`, `Close Profitable`, `Close Losing`, `Close All BUY`, `Close All SELL`, `Close Over`, `Close Under`).

3. Zero-Delay Bot Engine, Bot Builder & Seeded Strategies (`bot-engine-service.ts`, `BotBuilderPage.tsx`, `TradingBotsPage.tsx`):
   - **Zero Password Gate**: Directly accessible without any unlock modal or `requireBotAnalyserGate` middleware.
   - **Instant Startup & Tick Evaluator**: `startBotSession` immediately subscribes to the symbol, fetches the last **25 historical ticks** (`fetchTickHistory(..., 25)`), stores up to 20 prices, and fires `evaluateAndExecuteBotTick` immediately on the latest price with **zero tick-waiting delay**.
   - **Signal Modes**: Supports `DIGITOVER`, `DIGITUNDER`, `DIGITEVEN`, `DIGITODD`, `DIGITDIFF`, `DIGITMATCH`, `CALL`/`PUT` (momentum vs 5-tick average), and `MULTUP`/`MULTDOWN`.
   - **Live TP/SL Monitoring & Martingale**: `attachTickEvaluator` listens to every live Deriv tick, checks all `OPEN` rows in `virtual_orders` for TP/SL price hits (preventing duplicate closes via `closingOrderLocks`), closes real Deriv contracts via `closeDerivContract` (or credits/debits `virtual_workspace_balance` in virtual mode), increments session wins/losses/P/L, doubles/multiplies stake by `martingale` factor on loss (resetting to `baseStake` on win), creates DB notifications, broadcasts `order_closed` / `bot_order_opened` over WebSocket, and supports instant `Close All Bot Orders`.
   - **Bot Builder**: Supports Blockly XML import (`<field name="SYMBOL_LIST">`, `<field name="AMOUNT">`) and XML export, custom contract type/barrier/duration/TP%/SL%/Martingale inputs, and live telemetry polling.
   - **Pre-Seeded Strategies Catalog (`bot_strategies`)**: `07_Over_Hit_n_Run`, `AutoDifferbylegoo`, `MagicRecovery`, `Autovolt5Probot1`, `AlphaVersion2026Edition`, `SignalSniperAutoBot` across `Free Bots`, `Scalper Bots`, and `SpeedBots`.

4. Live Market Analyser, Bulk Trader & Martingale Risk Calculator (`AnalysisToolPage.tsx`, `BulkTraderPage.tsx`, `RiskCalculatorPage.tsx`):
   - **Market Analyser**: Connects browser WebSocket directly to Deriv (`fetchDerivTickHistoryDirect` + `subscribeDerivTicksDirect` with `/api/market/digit-analysis` fallback), renders 4 sub-tabs (`Dcircles` 0–9 circular digit distribution heatmap highlighting hottest green & coldest red digits, `Signals` with **RSI(14)** & trend bias, `Over/Under` barrier probability bars, `Rise/Fall` parity & directional streaks), plus 1-click instant trade execution buttons.
   - **Bulk Trader**: Live digit/parity feed + concurrent batch execution (`1–25` orders via `POST /api/orders/bulk`) for `Even/Odd`, `Over/Under`, and `Rise/Fall`, plus instant bulk-close controls.
   - **Martingale Risk Calculator**: Takes Initial Capital (USD) and computes exact `Stake (2% of Capital)`, `Take Profit (5x Stake)`, and `Stop Loss (4 Consecutive Losses Sum = 15x Stake)`.
   - **Copy Trading / Portfolio Sync, Reports, Notifications & Learning Hub**: Live account & scope monitor, filterable order & Deriv statement ledger, notification inbox with read-state sync, and educational guides.
